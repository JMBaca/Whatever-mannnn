# NEON RIFT: OVERDRIVE

Mobile-first arena survival game. Eight weapons, three abilities, a 3600 × 2600 arena, local high scores and offline play.

## iPhone installation

Enable GitHub Pages from main / (root). Open the deployed HTTPS URL in Safari and choose Share → Add to Home Screen. Offline caching requires a successful initial online visit.

## Controls

Drag to move; weapons auto-fire. Tap DASH, NOVA and VOID. Desktop: WASD, Space, Q and E.
